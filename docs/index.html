ClimaLink
Smart Climate Station

A Java Swing desktop app that watches room temperature and humidity in real time over USB Serial, and opens a window, changes a status light and sounds an alarm when the climate gets uncomfortable.

DHT11sensor
3actuators

GitHub repositoryProposal

01

Overview

The Arduino reads a DHT sensor every second and streams the values to the Java app. In AUTO mode the Arduino decides by itself: above the temperature or humidity limit it opens the servo window, turns the LED red and beeps. In MANUAL mode the user drives the window, LED and buzzer from the GUI.

Useful for a greenhouse, server closet or classroom where ventilation should react to the climate. The prototype was first built and tested in Wokwi, then run on a real Arduino UNO from the lab.

04

Java GUI

  • Connection bar — COM port list, refresh ↻, Connect/Disconnect, status (timeouts, errors, reconnecting).
  • Live cards — temperature, humidity, window angle, alarm (green OK / red ALARM).
  • Chart — last 60 temperature and humidity readings.
  • Controls — AUTO/MANUAL toggle, window slider 0–180°, temperature limit, LED colours, buzzer, ▶ Demo scenario, Log CSV.
  • Serial log — every sent (>) and received (<) line with a timestamp.
05

Serial Protocol

USB Serial, 9600 baud, 8N1, ASCII. One message = one line ending with \n. Fields separated by ;, values as key=value. Every command gets a reply.

DirMessageMeaning
A→JHELLO;ClimaLink;v1.0Board ready
A→JDATA;T=24.5;H=52.0;WIN=0;MODE=AUTO;ALARM=0Telemetry every RATE ms
A→JACK;<cmd> · ERR;<code>Reply to a command
J→APING → PONGHealth check (watchdog)
J→AMODE AUTO | MODE MANUALWho controls actuators
J→AWIN OPEN | WIN CLOSE | WIN 0–180Servo angle (manual)
J→ALED r g bRGB 0–255 (manual)
J→ABUZZ ON | BUZZ OFFBuzzer
J→ATHR T 28 · THR H 70Alarm limits
J→ARATE 200–10000Telemetry interval (ms)

Example session:

< HELLO;ClimaLink;v1.0
< DATA;T=24.3;H=51.0;WIN=0;MODE=AUTO;ALARM=0
> MODE MANUAL
< ACK;MODE MANUAL
> WIN 90
< ACK;WIN 90
< DATA;T=29.1;H=48.0;WIN=90;MODE=MANUAL;ALARM=1
> WIN 500
< ERR;BAD_ANGLE

Error codes: UNKNOWN_CMD, BAD_ANGLE, BAD_LED, BAD_RATE, WIN_IN_AUTO, LED_IN_AUTO, SENSOR_READ.

07

Results

  • Live temperature and humidity in the GUI every second, with a chart.
  • AUTO: above 28 °C the window opens, LED turns red and the buzzer beeps; it returns to green when it cools.
  • MANUAL: the slider moves the servo, buttons set LED colour and buzzer; every command is acknowledged.
  • Wrong port, unplugged cable, silent board and invalid commands produce clear messages; the app reconnects automatically.
  • Demo mode runs the whole scenario in under 20 seconds.
08

Reflection

Difficult: reading serial data without freezing the GUI — solved with a background thread and SwingUtilities.invokeLater. Keeping the Arduino responsive while beeping — solved by replacing delay() with millis() timing.

Learned: designing the protocol first made both sides testable separately (Wokwi Serial Monitor for Arduino, the log panel for Java).

Next: a humidity-driven fan (L9110 module, KS0168), an LCD on the board, and a history viewer for the CSV file.
